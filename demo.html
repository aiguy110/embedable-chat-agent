Embeddable Chat Widget Demo

👋 Welcome!
This page demonstrates the embeddable chat widget. Click the chat icon in the bottom-right corner to start chatting!

About This Demo

This is a simple demonstration of the embeddable LLM chat agent. The widget is loaded via a script tag and initialized with a base URL pointing to the backend server.

How It Works

  1. The widget script is loaded from the backend server
  2. It's initialized with the API endpoint URL
  3. User messages are sent to the backend via POST requests
  4. Responses stream back in real-time using Server-Sent Events (SSE)
  5. If MCP servers are configured, the agent can use tools

Integration Code

<!-- Add this to your HTML page --> <script src="http://localhost:3000/widget.js"></script> <script> EmbedChat.init({ baseURL: 'http://localhost:3000' }); </script>

Developer Console Snippet

Want to test the widget on an existing page? Copy and paste this into your browser's developer console:

(function() { const script = document.createElement('script'); script.src = 'http://localhost:3000/widget.js'; script.onload = function() { EmbedChat.init({ baseURL: 'http://localhost:3000' }); console.log('Chat widget loaded! Click the bubble in the bottom-right.'); }; script.onerror = function() { console.error('Failed to load chat widget. Is the server running?'); }; document.head.appendChild(script); })();

Try it: Open any website, press F12 to open DevTools, paste this code in the Console tab, and press Enter!

🔧 Configuration
Make sure you've:
  1. Configured config.yaml with your LLM settings
  2. Set your API key in backend/.env
  3. Built the frontend: cd frontend && npm run build
  4. Started the backend: cd backend && npm run dev
